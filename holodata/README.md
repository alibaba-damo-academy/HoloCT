# HoloDATA

Dataset metadata, annotations and train/test splits for HoloCT.

| Folder | Datasets and contents |
|---|---|
| `seg_data/` | Segmentation and lesion-screening metadata for the datasets listed below. |
| `txt_data/` | Sample identifiers and splits for 3D-RAD, AbdomenAtlas 3.0, AMOS-MM, CT-RATE, DeepTumorVQA, FLARE-2025, INSPECT, Merlin and RadGenome; full BIMCV annotations. |
| `multiseg_data/` | Full AMOS grounded and DeepTumorVQA grounded annotations; sample identifiers and splits for RadGenome grounded VQA/reporting and ReXGroundingCT. |

`seg_data/` contains AbdomenCT-1K, AMOS22, Medical Segmentation Decathlon (colon, hepatic vessel, liver, lung, pancreas and spleen), AeroPath, VerSe, TotalSegmentator, Pancreas-CT, BTCV, CRLM-CT, HaN-Seg, KiTS23, KiPA22, CHAOS, FLARE22/23, CT-ORG, LIDC-IDRI, SLIVER07, LUNA16, COVID-19-CT-Seg, CTPelvic1K, Couinaud-Liver, DAP-Atlas, FUMPE, LNDb, MM-WHS, PDDCA, PARSE2022, SEGA/AVT, SegRap2023, SegTHOR, Seg-CQ500, NSCLC-Radiomics, PleThora, WORD, RAOS, CT-ICH, Mediastinal-Lymph-Node-SEG, 3D-IRCADb-01, NSCLC-Radiogenomics, PanTS, PASTA-Gen-30K, AbdomenAtlas 3.0, LiMT, ULS23, CT-Lymph-Nodes, HCC-TACE-Seg, QUBIQ2021, PANORAMA, TotalSegmentator liver lesions, MHB-SEG, Pediatric-CT-SEG, VEELA2025, PENGWIN and Adrenal-ACC-Ki67.

Full annotation files are `txt_data/BIMCV.json`, `multiseg_data/AMOS_gournded.json` and `multiseg_data/DeepTumorVQA_grounded.json`. The BIMCV annotations were generated by the HoloCT authors using an LLM.

To avoid redistributing source annotations, the other text and grounded JSON files contain only `filename` and `ct_path` with their train/test splits.

JSON split dictionaries use `train` and `test`. RadGenome grounded reporting uses separate `Radgenome_grounded_train.json` and `Radgenome_grounded_test.json` files.

Match source scans using `filename` and set `ct_path` to the local CT location. Numeric segmentation filenames follow the dataset identifiers in [`dataset_info.py`](../utils/corpus/dataset_info.py).
